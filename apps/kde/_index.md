# Desktop (KDE Plasma)

A modern, highly customizable desktop environment powered by Plasma 6.
It aims to provide a feature-rich, sleek, and user-friendly experience built natively for modern display servers like Wayland.

## Installing applications

In this configuration, KDE Plasma is set up to use **Flatpak** seamlessly integrated with the **Discover** software center.
Flatpak is a software utility for software deployment, package management, and application virtualization for Linux. By using Flatpak in user mode, users can easily browse, install, and manage applications directly from the Discover storefront without needing administrative privileges or modifying the base Docker image.
This setup enhances flexibility and security, providing a familiar "app store" experience where users can add or remove applications independently of the underlying system.
